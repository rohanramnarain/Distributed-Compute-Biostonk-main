Feature ImportancesRequires model

A ranked list of the inputs a trained model uses most overall. A higher feature can influence decisions more strongly, but importance alone does not show direction or causality.

Not generated: the current comparison is cosine retrieval, not a fitted outcome model.

Permutation ImportanceRequires model

Randomly scrambles one feature at a time and measures the drop in held-out performance. A larger drop suggests the fitted model relies more heavily on that signal.

Requires a frozen model, held-out evaluation cohort, target definition, and baseline metric.

fANOVA ImportancesRequires model

Estimates how much outcome variance is attributable to individual factors and interactions across a defined parameter space.

Requires a fitted model and documented feature ranges; it is not applicable to the current nearest-neighbor ranking alone.

SHAP SummaryRequires model

A cohort-level view of how features push fitted model outputs up or down. Each point represents one evaluated record and the spread shows variation in influence.

Requires a versioned predictive model and representative background dataset.

SHAP WaterfallRequires model

Explains one fitted-model output step by step, showing how each feature moves the output away from its baseline value.

No waterfall is shown for similarity retrieval because there is no outcome-model baseline or prediction to decompose.

Probe CoefficientsRequires labels

A diagnostic probe can test which directions inside an embedding representation align with a carefully defined label. Coefficients describe association in the probe, not causal clinical drivers.

The current sentiment labels cannot be relabeled as clinical success or failure.

ROC CurveRequires outcomes

Plots sensitivity against false-positive rate across decision thresholds. Curves nearer the top-left indicate stronger separation on a held-out labeled cohort.

Requires explicit binary clinical outcomes and an untouched evaluation set.

Precision-Recall CurveRequires outcomes

Shows the tradeoff between positive predictive value and sensitivity. It is especially informative when the positive outcome is rare.

Requires approved outcome labels and a declared positive class; sentiment annotations are insufficient.
